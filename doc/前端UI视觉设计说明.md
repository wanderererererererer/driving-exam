# 前端 UI 视觉设计说明（工作台与全站浅色规范）

> 本说明只记录当前已落地、可由源码与构建证据支持的内容；浏览器像素级验收仍需在 Docker/浏览器环境完成。

## 一、设计方向

采用轻量现代浅色风格：

- 页面背景 `#F5F7FA`，卡片 `#FFFFFF`；
- 低饱和品牌蓝 `#7597D5`；
- 浅蓝选中背景 `#E8EFFB`；
- 边框 `#DCE3EC`；
- 主文字 `#263449`，次级文字 `#687589`；
- 语义状态使用柔和的成功/警告/危险色。

设计令牌集中在 `frontend/src/assets/main.css`，页面通过 `var(--app-*)` 和 Element Plus 变量复用，不重复散落调色。

## 二、设计令牌与公共控件

已落地：

- `--app-primary`、`--app-primary-soft`、`--app-bg`、`--app-surface`、`--app-border`、`--app-text`、`--app-text-secondary`；
- `--app-radius` / `--app-radius-sm` / `--app-radius-lg`；
- `--app-shadow-sm` / `--app-shadow`；
- 字体、页面标题、区块标题、辅助说明字号；
- Element Plus 主题桥接：primary、success、warning、danger、text、border、radius、shadow、table、dialog、tag、tabs、tree、upload 等。

公共布局：

- `app-layout`、`app-header`、`app-brand`、`app-aside`、`app-menu`、`app-main`；
- 顶部栏 64px，侧边栏 224px；主内容区左右 24px、上下 20px；
- 内容最大宽度 1680px，并在桌面宽度内自适应铺开，不再限制在 1440px 的窄中央；
- 页面标题 24px、管理端工作台 26px，区域标题 16px，正文/表格 14px；
- 表格表头 13px，辅助说明 12–13px，核心数值 34–40px。
- 菜单选中态使用角色色浅底 + 角色色文字；
- 登录页使用左侧品牌说明 + 右侧登录卡片的双栏布局，窄屏自动收敛为单栏。

## 三、三端差异化

### 学员端

- 角色强调色：低饱和学习蓝 `#7597D5`；
- 工作台突出学习进度、错题复习、预约和消息；
- 数学/进度信息优先，下方保留理论学习进度、最近预约与快捷入口；
- 增加“科目一模考”“考试记录”入口。

### 教练端

- 角色强调色：低饱和青蓝 `#5E9FB3`；
- 工作台突出待处理预约、已确认预约、绑定学员和未读消息；
- 预约列表和学员概况以列表/标签为主，强调扫读效率；
- 不展示没有日期筛选支持的“今日预约”。

### 管理端

- 角色强调色：低饱和靛蓝 `#7B86C7`；
- 工作台为单行统计概览条 + 不对称主工作区：左侧待处理/最近预约，右侧用户构成/快捷入口；
- 统计卡不再重复四张同尺寸白卡，改为一个概览面板内的分级指标；
- 用户构成用真实数量比例进度条表达，快捷入口采用图标型操作块；
- 统计卡、角色分布与列表分层，信息密度略高但保持可读；
- AI 问答数明确标注为历史记录数，不冒充 RAG 在线状态。

## 四、页面覆盖

已注册并纳入视觉规范的实际页面：

- 登录、404、ComingSoon；
- 学员：工作台、科目首页、刷题、错题本、智能问答、学情分析、聊天、个人中心、模拟考试列表/答题/报告/记录、预约；
- 教练：工作台、学员管理、预约管理、聊天、个人中心；
- 管理：工作台、用户、绑定、知识点、题库、试卷、预约查看、AI 统计、个人中心。

全站通过 `main.css` 的 Element Plus 变量覆盖和公共布局样式统一；按钮、输入框、表格、分页、弹窗、标签、提示、空状态、树、上传等控件由公共样式统一。业务页面保留原有组件结构和接口。

## 五、数据与权限

- 学员：`/api/student/**` 与 `/api/auth/me`；
- 教练：`/api/coach/**` 与 `/api/auth/me`；
- 管理：`/api/admin/**` 与 `/api/auth/me`；
- 三端工作台均使用真实 API，不使用静态数字；
- 单接口失败不显示为 0，使用“加载失败”或分区告警；
- 管理员 AI 问答数是历史记录统计，不宣称 RAG 可用性。
