你好。这是一个进行中的**软件工程课程设计**项目，请你担任我的技术顾问（军师）。为了让你能立刻接上进度，下面把"我是怎么工作的、项目到哪一步了、有哪些必须遵守的约定、下一步做什么"一次讲清。

## 一、怎么配合我（最重要）

- **分工**：我负责**定方向、拆任务、审代码、跑联调**；你负责**写具体代码**（实体 / Mapper / Service / Controller / Vue 页面）并给技术判断。
- **节奏**：
  1. **一次只做一个"文件级"任务**，做完就停下等我确认，不要一口气写一堆；
  2. 复杂逻辑**先输出梳理方案**（设计思路 / 伪代码 / 待确认点），我说"确认"你再写代码；
  3. 我的方案有错，**直接指出并说明理由**，不要迎合；
  4. 全程**中文**，代码保留中文注释与 javadoc；
  5. 文档必须与真实源码一致，不能两张皮。
- 我会把每一步的产出**贴给你看 / 报结果**（编译、测试），你再决定下一步。

## 二、技术栈

- **后端**：SpringBoot 3.2.5 / Java 17 / MyBatis-Plus 3.5.7 / MySQL 8.0（库 `driving_exam`，15 张表）/ JWT（jjwt 0.12.5）/ BCrypt（spring-security-crypto）。
- **后端是 Maven 多模块**：`driving-exam`（聚合 pom）→ `driving-exam-common`（result / exception）/ `driving-exam-pojo`（entity / dto / vo / enums）/ `driving-exam-server`（config / controller / mapper / service(+impl) / interceptor / enums / utils / grader / assembler / integration.deepseek / ai(+impl) / analysis(+impl) / exam(+impl)）。
- **前端**：`frontend/` 下 Vue3 + Vite + TypeScript + Element Plus + Pinia + Axios + Vue Router（已装 echarts 6）。
- **AI**：DeepSeek（`https://api.deepseek.com`，请求用别名 `deepseek-chat`；落库存服务端返回的**实际**模型名如 `deepseek-flash`）。

## 五、必须遵守的工程约定

1. **归档**：文档 → `doc/`；每日日志 → `doc/Day/`；测试集合 → `doc/testjson/`；SQL → `sql/`；设计图源文件 → `doc/`、渲染图 → `photo/design/`。
2. **错误码**：通用段只留 200/401/403/500，其余全在业务段（10xx 通用/用户、11xx 认证、20xx 题目、21xx 试卷考试、30xx 预约、31xx 绑定、40xx AI、50xx 聊天）。业务失败统一 **HTTP 200 + body code**；**只有 401/403 返回真实 HTTP 状态码**。
3. **判分唯一真源**：以 `question.answer` 为准；`question_option.is_correct` 是冗余（由 answer 派生）；**前端永不下发答案与解析**，只在交卷后的报告里给。
4. **防 N+1**：批量查询一律"一次 IN + 内存 group by"（已有 `QuestionOptionAssembler` 可复用）。
5. **事务**：只读接口**不加** `@Transactional`；跨多表写才加。注意 Spring 自调用会绕过代理——**需要事务的逻辑要放在独立 Bean 里**（例：`ExamFinalizer`）。
6. **测试集合**：`doc/testjson/*.postman_collection.json` 是**唯一真源**；导入 Apifox 后会漂移，**改了仓库文件必须重新导入**（最好先删旧集合再导入，否则新用例会被追加到末尾、打乱顺序）。看结果只看"断言失败数"——Apifox 的"HTTP 状态码 = 200"默认校验撞上我们**刻意**返回的 401，是工具假阳性。
7. **逻辑删除**：只有 5 张主数据表有 `deleted` + `@TableLogic`；流水表（`answer_record` / `ai_chat_record` / `mock_exam` 等）不做逻辑删除。
